# 🎬 AI-Powered Video Transcriber

An advanced Video & YouTube Transcriber that directly converts video and audio into accurate text transcripts. Built with **Faster-Whisper** and **Streamlit** to ensure fast, exact speech-to-text extraction.

### Features
- 🚀 **YouTube & Direct Upload**: Input YouTube URL or upload MP4, MKV, AVI, MOV, WebM, MP3, WAV.
- ⚡ **Faster-Whisper Integration**: High-performance CTranslate2 inference.
- 📝 **Export Options**: Download transcripts directly as TXT.
- 🎯 **Ground Truth Transcription**: Exact voice reproduction without AI hallucination.
